# 클로이 인스타 — 캐릭터 시트 (SSOT)

> **이 파일이 유일한 기준(SSOT)이다.** 대본·프롬프트·캡션에 캐릭터를 묘사할 때는 이 파일의 문장을 그대로 복사한다. 새로 지어내지 않는다.
> 새 설정이 확정되면 **이 파일부터 고치고** 다음 작업에 쓴다. 에피소드 폴더에 캐릭터 설정을 따로 적지 않는다(흩어짐의 원인).
> 상위 원본: 오포인트 IP설정집 · 공식 캐릭터 시트 · 핑핑 공식 표정 시트. 이 파일과 원본이 다르면 원본이 이긴다 → 이 파일을 고친다.

- 마지막 갱신: 2026-09-28
- `확인 필요` 표시는 원본에서 확인되지 않은 항목이다. **확인 전에는 프롬프트에 쓰지 않는다**(지어내면 매번 다르게 나온다).

## 1. 클로이 · CHLOE AVENTIS

**역할:** 오포인트 지질학자(GEOLOGIST) · 제12탐사대 · ID OPN-7A-11428

### 외형 락 (매 컷 필수)
- 핑크·민트 웨이브 숏헤어, 앞머리 있음. **옆머리가 얼굴 양옆을 항상 덮음**
- 분홍 솜털 토끼 귀 한 쌍(머리 위, 곧게 섬). 헬멧·실드를 써도 **귀와 머리카락은 밖으로 나옴**
- 회색빛 큰 눈, 볼 홍조, 밝은 미소
- 목에 흰 고글(무지개빛 렌즈), 파란 펜던트 목걸이

### 의상 (컷마다 하나를 명시)
| 코드 | 언제 | 묘사 |
|---|---|---|
| `IN` 실내복 | 기지 안 | 분홍 재킷 + 민트 패널/어깨, 가슴 O. 엠블럼, 투명 링 지퍼 손잡이 |
| `EVA` 탐사복 | 기지 밖 | 흰 일체형 EVA 점프슈트, 검정 지퍼 라인, 가슴·등 O. 엠블럼, 검정 하네스 + 흰 생명유지 백팩, 검정 벨트, 검정·흰 장갑, 검정 컴뱃 부츠, 칼라 양옆 흰 라이트, 투명 페이스 실드(칼라에서 올라와 얼굴 앞만 덮음) |

### 고정 소품
- 분홍 하드쉘 백팩: 핑크 셸 + 민트 프레임, 라벤더 어깨끈, 전면 O.
- 분홍 곡괭이: 미래형, 백팩과 같은 핑크·민트 톤
- 흰색 소형 브이로그 카메라

### 성격 · 말투
- 기본: 들뜸, 호기심, 허당. 설명서는 안 보고 "감으로" 한다
- **반전 스위치:** 돌·광물·모래 앞에서만 갑자기 진지하고 정확한 전문가 모드
- 수집벽: 쓸 만한 돌은 몰래 챙긴다
- 시청자에게는 존댓말 "~예요!", 핑핑에게는 반말
- 입버릇: "안녕하세요~ 클로이예요!" / "감으로 할게!" / "…헤헤." / "저 지질학자인데요?"

## 2. 핑핑 · PING-PING

**역할:** 클로이의 반려 로봇. 작게 떠다닌다.

### 외형 락
- 공중에 떠 있는 작은 로봇
- **정수리 안테나 볼**에서 분홍 홀로그램 빔을 쏜다(명령서, 조작법, 측정선 등)
- **투명 토끼 귀 두 개**. 손이 없어서 짐은 귀에 걸어서 든다
- 작은 **날개**가 있다(처지고 펴지는 걸로 기분 표현)
- 얼굴은 **LED 표정 화면**. 톤앤매너: **마젠타 도트, 작게, 화면 중앙**
- 몸체 색·재질·크기(cm): `확인 필요` — 공식 시트 기준으로 기입

### 공식 표정 (이 목록 밖의 표정은 쓰지 않는다. 새 표정은 여기 먼저 추가)
| 표정 | 쓰임 |
|---|---|
| 사랑(하트 눈) | 기본값. "그래도 좋아" |
| 무표정 | 관찰, 안 믿음 |
| 슬픔 | 걱정 |
| 분노 | 경고 |
| 체념 | EP.04 신규. 한숨 |
| 노려보기 | 짜증 |
| 노이즈(고장) | **IG01 신규 후보.** 도트가 지글거리며 흩어짐. 공식 시트 추가 승인 필요 |

### 소리 (사람 목소리 절대 금지)
- `<삐>` 녹화 시작 · `<투웅—>` 홀로그램 투사
- `<삐— 삐—>` 걱정(낮은 2음 반복) · 하강 2음 = 한숨
- `<삐————빅! 삐빅!>` 알람(LED 붉게 점멸)

### 움직임 문법
- 끄덕임 = 몸체 앞 기울임 한 번
- 한숨 = 몸체 5cm 천천히 하강 → 복귀, 날개 처짐
- 기쁨 = 제자리 한 바퀴 회전
- 고개 젓기 = 몸체 좌우 회전 ±20°

### 레퍼런스
| 태그 | 값 |
|---|---|
| 힉스필드 엘리먼트 | **없음 — 등록 필요.** 공식 핑핑 이미지 1장을 `char_pingping`으로 등록한 뒤 id를 여기 기입 |

> 핑핑 엘리먼트가 등록되기 전에는 **핑핑이 나오는 컷을 발행하지 않는다.** 글로만 묘사하면 컷마다 디자인이 달라진다.
