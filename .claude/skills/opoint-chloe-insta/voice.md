# 멘트 규칙: 캡션, 카드 문구, 스토리, 댓글, 멘션

인스타의 모든 글은 **클로이 1인칭**으로 쓴다. 운영자 말투("오늘은 클로이가~")는 쓰지 않는다.

## 1. 말투

- 팔로워에게 존댓말 "~예요!", "~했어요!". 핑핑을 부를 때만 반말
- 짧게 끊는다. 한 줄에 한 문장
- 핑핑의 말은 **소리로만** 적는다: `[삐빅]`, `[투웅—]`, `[삐— 삐—]`. 번역을 달 때는 클로이가 해석해 준다("…라고 하네요")
- 팀장은 "팀장님"이라고 부른다. 이름(바렌 토르카)은 명령서 인용할 때만 쓴다
- 이모지 팔레트(3개 이내): 🐰 🩷 🪨 ✨ 💫 🤖 — 이 밖의 이모지는 쓰지 않는다
- 금지: 다른 크루 이름, 설정집에 없는 사실, 과한 유행어

## 2. 캡션 구조

```
[훅 한 줄: 상황 또는 대사 인용]

[본문 2~3줄: 클로이 시점]
[핑핑 소리 한 줄]

[질문 또는 떡밥 한 줄 → 댓글 유도]

[멘션]
[해시태그 8~12개]
```

## 3. 멘션 (@)

| 슬롯 | 계정 | 언제 |
|---|---|---|
| 공식 계정 | `@확인 필요` (오포인트 공식) | 매 게시물 |
| 협업/브랜드 | 해당 편에 있을 때만 | 광고, 협찬 편 |

- 계정 핸들은 **확정 전에는 비워 둔다.** 추측으로 채우지 않는다(남의 계정을 태그할 위험)
- 게시물 안의 사람 태그도 같은 계정만

## 4. 해시태그

- 고정 (항상): `#클로이 #ChloeAventis #핑핑 #오포인트 #OPoint #타르시스 #제12탐사대 #aiart`
- 편별 가변 2~4개: 편 주제(예: `#모래폭풍 #로봇수리`)
- 전체 12개 이하

## 5. 카드 문구 (캐러셀 장 위에 편집으로 얹는 글)

- 커버(1장째): 12자 이내, 두 줄까지. 가운데 3:4 안에
- 나머지 장(최대 2장): 한 장에 한 줄, 20자 이내. 클로이 말투 그대로(대사나 속마음)
- 이미지 생성 때 글자를 넣지 않고, 프롬프트에 비워 둘 자리만 지정한다

## 5-1. 커버 톤

- 12자 이내, 두 줄까지
- 유튜브 썸네일 톤 재사용: 흰 굵은 글씨 + 분홍 테두리 프레임
- 피드 3칸 한 줄이 한 톤으로 몰리지 않게: 셀카 얼굴 → 핑핑 클로즈업 → 풍경이나 광물 순으로 돌린다

## 6. 댓글 답글 세트

편마다 아래 유형별로 1~2개씩 미리 써 둔다. 답글도 클로이 1인칭.

| 유형 | 예시 톤 |
|---|---|
| 칭찬 | "헤헤 고마워요! 핑핑이도 하트 띄웠어요 🩷" |
| 핑핑 걱정 | "핑핑이 이제 완전 멀쩡해요! [삐빅] ← 이게 괜찮다는 뜻이에요" |
| 설정 질문 | 설정집에 있는 것만 답. 모르면 "그건 비밀이에요 🤫"가 아니라 "다음에 알려드릴게요!" |
| 팀장 언급 | "팀장님은… 보고서 얘기만 하세요…" |
| 악플, 민감 이슈 | 답하지 않는다. 운영자에게 넘긴다 |
