# 클로이 인스타그램 제작

영상 생성 규칙(LEAN 프롬프트, 한글은 중괄호 안에만, 검증 2회, 480p→1080p, 한 컷 1회 발행, 진행표 기록)은 **`opoint-yeon-episode` 스킬을 그대로 따른다.** 이 스킬은 인스타에만 다른 점과 클로이·핑핑 전용 규칙만 담는다.

## 힉스필드 계정: 반드시 '오포인트'

- 힉스필드 호출 전에 `list_workspaces`로 확인한다. 선택된 워크스페이스 id가 **`23be883d-aa3b-4171-8543-946428aff831`(오포인트)** 가 아니면 조회·업로드·생성 모두 하지 않고 멈춘 뒤 상은님께 알린다
- 보조 확인: `show_reference_elements`에 `char_o4_pingping`이 보여야 한다
- 오포인트 계정은 크레딧이 적을 수 있다. 발행 전 `get_cost`로 비용을 확인하고 잔액과 함께 보고한다
- 엘리먼트·media_id는 계정마다 다르다. 다른 계정에서 읽은 ID를 섞어 쓰지 않는다
- 연결된 계정을 바꾸는 건 상은님이 claude.ai 커넥터 설정에서 힉스필드를 오포인트 계정으로 다시 연결해야 한다

## 0. 파일 구조: 흩어지지 않게

```
opoint-chloe-insta/
  SKILL.md           ← 이 파일 (프로세스)
  characters.md      ← 캐릭터 시트 SSOT. 캐릭터 묘사는 여기서만 복사
  episode-bank.md    ← 조합표 + 로테이션 로그 (지난 편 기록)
  voice.md           ← 멘트 규칙: 캡션, 스토리, 댓글 답글, 멘션
```

- 에피소드 산출물은 `.claude/insta/IG{nn}_{제목}/`에 둔다
- **에피소드 폴더에 캐릭터 설정을 다시 적지 않는다.** 필요하면 characters.md를 링크한다
- 새 표정, 새 소품, 새 설정이 생기면 characters.md를 먼저 고치고 "마지막 갱신" 날짜를 바꾼다

## 1. 파이프라인

```
① 조합 뽑기      episode-bank.md의 5칸에서 고름 + 로테이션 로그로 3편 규칙 확인
② 로그라인      "[클로이의 면] + [관계] + [형식]" 한 줄
③ 대본·컷표     컷 · 초 · 클로이 대사 · 핑핑 LED/소리 · 카메라
④ 캐릭터 락 체크  아래 2절 표를 컷마다 실제로 확인
⑤ 프롬프트       opoint-yeon-episode LEAN 구조, 9:16, 엘리먼트 참조
⑥ 검증 2회      적대적 검수 서브에이전트 (칭찬 금지, 결함만)
⑦ 480p 발행 → 상은님 검수 → OK컷만 1080p
⑧ 멘트          voice.md 규칙: 캡션, 커버 문구, 스토리 3장, 댓글 답글
⑨ 기록          로테이션 로그 한 줄 + characters.md 연속성 표 갱신
```

**①~④와 ⑧은 크레딧이 들지 않는다.** 한 번에 끝까지 만든다. ⑦ 발행은 상은님 확인 후에만 한다.

## 2. 캐릭터 락 체크리스트 (발행 전 컷마다)

| 항목 | 확인할 것 |
|---|---|
| **폐쇄 캐스트** | "여자 정확히 1명 + 작은 떠 있는 로봇 정확히 1대, 그 외 없음"이 들어갔는가 |
| **클로이 머리** | 핑크·민트 웨이브 + 옆머리가 얼굴 양옆을 덮음 + 분홍 솜털 토끼 귀 |
| **클로이 의상** | `IN` 또는 `EVA` 중 하나를 명시했는가 (섞지 않음) |
| **클로이 레퍼런스** | 의상에 맞는 것: `IN` → `char_o4_chloe`, `EVA` → `char_o4_chloe_suit` (id는 characters.md) |
| **핑핑 레퍼런스** | `char_o4_pingping` 참조가 있는가. **없으면 발행 중단** |
| **핑핑 소리** | 전자음만. 핑핑을 화자로 지칭하지 않았는가 (셈 규칙 동일) |
| **핑핑 표정** | characters.md 공식 표정 목록 안의 것인가. 마젠타 도트, 작게, 중앙 |
| **팀장** | 화면에 없음. 명령서 홀로그램 또는 통신음만 |
| **글자** | 명령서 홀로그램은 "읽히지 않는 흐릿한 글줄"로. 읽히는 글자 없음 |
| **연속성** | characters.md 5절 표와 맞는가 (외벽 상태, T-03 등) |

## 3. 인스타 전용 규격

| 형식 | 비율 | 해상도 | 길이/장수 | 비고 |
|---|---|---|---|---|
| 릴스 | 9:16 | 1080×1920 | 30~45초 (컷 3~5개) | 첫 2초 안에 훅. 하단 20%와 오른쪽 12%는 UI에 가려지므로 자막·얼굴을 두지 않음 |
| 캐러셀 | 4:5 | 1080×1350 | 5~8장 | 1장째가 커버. 마지막 장은 질문이나 떡밥 |
| 스토리 | 9:16 | 1080×1920 | 3장 | 투표, 퀴즈, 질문 스티커 |

- 씨댄스 `aspect_ratio: "9:16"`
- 유튜브 에피소드(16:9)를 재활용할 때는 세로로 크롭하지 말고 **세로로 다시 생성**한다(셀카 구도는 세로가 자연스러움)
- 한 편의 릴스는 한 가지 감정 결말만 가진다

## 4. 조합표 · 로테이션

`episode-bank.md` 참고. 핵심 규칙:
1. **3편 규칙**: 연속 3편 안에서 같은 형식이나 같은 결말을 반복하지 않는다
2. **떡밥 한 줄**: 매 편 다음 편으로 이어질 장치 하나 (T-03, 외벽, 팀장 명령서 등)
3. **4주 비율**: 코미디 50%, 전문가·정보 25%, 감성·미스터리 25%
