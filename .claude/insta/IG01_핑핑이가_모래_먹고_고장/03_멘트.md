# IG01 멘트

규칙: [voice.md](../../skills/opoint-chloe-insta/voice.md) · 클로이 1인칭 · 이모지 3개 이내

## 릴스 커버 문구

```
핑핑이가
고장 났어요
```
(흰 굵은 글씨 + 분홍 테두리. 배경은 C1의 뒤돌아보는 클로이와 노이즈 도트 핑핑)

## 캡션

```
폭풍은 지나갔는데… 핑핑이가 모래를 먹었어요 🥲

귀 안쪽까지 협곡 바닥 모래가 꽉 찼더라고요.
그래도 괜찮아요. 저 지질학자거든요.
모래는 제 전문이에요 🪨

[지직—] → [삐빅!]
이 소리 들리면 다 나은 거예요 🩷

여러분은 아플 때 누가 챙겨 줘요?

@확인_필요_오포인트공식

#클로이 #ChloeAventis #핑핑 #오포인트 #OPoint #타르시스 #제12탐사대 #모래폭풍 #로봇수리 #aivideo
```

## 스토리 3장 (릴스 올린 날)

| 장 | 화면 | 스티커 |
|---|---|---|
| 1 | C2 고글 쓴 클로이 정지 컷 + "지질학자 모드 ON" | 없음 |
| 2 | C3 노이즈 도트 핑핑 클로즈업 | **투표**: "핑핑이 다 나았을까?" 나았다 🩷 / 아직 [지직] |
| 3 | C4 마지막 프레임, 명령서 홀로그램에 동그라미 | **질문**: "핑핑이가 띄운 이거… 뭘까요?" (IG02 떡밥) |
