# IG01 멘트

규칙: [voice.md](../../skills/opoint-chloe-insta/voice.md) · 클로이 1인칭 · 이모지 3개 이내

## 카드 문구 (장 위에 편집으로 얹음)

| 장 | 문구 | 위치 |
|---|---|---|
| S1 커버 | 핑핑이가 / 고장 났어요 | 위 1/5 (흰 굵은 글씨 + 분홍 테두리) |
| S2 | 괜찮아. 나 지질학자잖아. | 왼쪽 아래 |
| S3 | 오늘은 일 안 해. 너랑 쉴 거야. | 아래 1/5 |

## 캡션

```
폭풍은 지나갔는데… 핑핑이가 모래를 먹었어요 🤖

귀 안쪽까지 협곡 바닥 모래가 꽉 찼더라고요.
그래도 괜찮아요. 저 지질학자거든요.
모래는 제 전문이에요 🪨

[지직—] → [삐빅!]
이 소리 들리면 다 나은 거예요 🩷

여러분은 아플 때 누가 챙겨 줘요?

@확인_필요_오포인트공식

#클로이 #ChloeAventis #핑핑 #오포인트 #OPoint #타르시스 #제12탐사대 #모래폭풍 #로봇수리 #aiart
```

## 스토리 3장 (피드 올린 날)

| 장 | 화면 | 스티커 |
|---|---|---|
| 1 | S2 고글 쓴 클로이 + "지질학자 모드 ON" | 없음 |
| 2 | S1 슬픈 핑핑 부분 확대 | **투표**: "핑핑이 다 나았을까?" 나았다 🩷 / 아직 [지직] |
| 3 | S3, 홀로그램에 동그라미 | **질문**: "핑핑이가 띄운 이거… 뭘까요?" (IG02 떡밥) |
